ПОЛНОЕ ОПИСАНИЕ СИСТЕМЫ TESTS (TRACE MODE 7)
Дата: 2026-03-14

1) Назначение системы
- Приложение TESTS — офлайн-система тестирования по темам TRACE MODE 7 и АСУТП.
- Есть 5 тестов:
  1. Уровень 1
  2. Уровень 2
  3. Уровень 3
  4. Уровни 4-5
  5. Итоговый (смешанный из первых 4)
- В одной попытке пользователю выдаются 20 вопросов.
- Время на попытку: 20 минут.

2) Что хранится в БД
- В базе tests_secure.db хранятся:
  - список тестов;
  - список вопросов каждого теста;
  - варианты ответов;
  - типы вопросов;
  - зашифрованные правильные ответы;
  - служебные поля для синхронизации итогового теста.
- База зашифрована паролем LiteDB (AES внутри LiteDB).

3) Основная логика данных
- Все встроенные тесты (1-4) загружаются из каталога вопросов в коде.
- Итоговый тест синхронизируется автоматически из тестов 1-4:
  - изменения вопроса в тесте 1-4 отражаются в итоговом;
  - новый вопрос в тесте 1-4 автоматически попадет в итоговый;
  - удаленный вопрос из теста 1-4 пропадет из авто-части итогового;
  - ручные вопросы, добавленные напрямую в итоговый тест, сохраняются.
- Встроен дедуп (удаление дублей):
  - для тестов в БД;
  - для итогового теста при сборке;
  - для выборки вопросов в попытке (контроль повторов и "семейств").

4) Как выбираются вопросы в попытке
- Из банка теста выбираются 20 вопросов случайно.
- Выборка уникальна:
  - нет полного дублирования вопроса в рамках попытки;
  - для теоретических вопросов учитывается "семейство" (термин в кавычках),
    чтобы похожие формулировки по одному и тому же термину не повторялись подряд.

5) Где ключевые файлы логики
- TestStorage.cs
  - загрузка/сохранение БД;
  - миграция и нормализация;
  - синхронизация итогового теста;
  - дедуп.
- DefaultTestCatalog.cs
  - встроенный пул вопросов.
- SecurityService.cs
  - шифрование/дешифрование ответов;
  - проверка ответов;
  - служебная криптология.
- test_panel.cs
  - логика прохождения теста;
  - таймер;
  - случайная уникальная выборка вопросов.

8) Как открыть БД (пошагово)
Вариант A (рекомендуется): LiteDB Studio
1. Скачайте LiteDB Studio (portable).
2. Откройте файл tests_secure.db.
3. Введите пароль БД:
   TM7_SECURE_DB_2026_!x9Yp4@mQ2
4. Откройте коллекцию tests.
5. Смотрите/проверяйте структуру тестов и вопросов.

Важно:
- Если приложение TESTS запущено, файл БД может быть заблокирован.
- Перед ручным открытием БД лучше закрыть TESTS.exe.

9) Перенос на другой компьютер
- Для полностью рабочего офлайн-переноса копируйте всю папку Release:
  - TESTS.exe
  - TESTS.exe.config
  - LiteDB.dll
  - Newtonsoft.Json.dll
  - tests_secure.db
- На целевом ПК нужен .NET Framework 4.8.
- После копирования логика и пул вопросов сохраняются.

10) Замечания по безопасности
- База шифруется паролем LiteDB.
- Ответы в вопросах хранятся в зашифрованном виде.
- Админка проверяет логин/пароль по хэшу+соли.
- Для реальной эксплуатации в аудитории рекомендуется периодически менять:
  - админ-пароль;
  - пароль БД;
  - часть банка вопросов.
